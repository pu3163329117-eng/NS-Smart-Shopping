Docker Self-Host Guide

Step 00

Install Docker (Windows + WSL2)

Windows version baseline

Recommended: Windows 10 Pro/Enterprise/Education 22H2 or Windows 11 22H2+.

winver systeminfo | findstr /B /C:"OS Name" /C:"OS Version" wsl --version

A. System checks (PowerShell as Admin)

winver systeminfo | findstr /i "Virtualization" wsl --status

B. Enable WSL2 (PowerShell as Admin)

wsl --install wsl --update wsl --set-default-version 2 wsl -l -v

C. Install Docker Desktop

Install from official Docker site and keep WSL2 integration enabled.

net localgroup docker-users "%USERNAME%" /add

D. Verify Docker in WSL terminal

docker --version docker compose version docker run --rm hello-world
Step 01

Install Docker (macOS)

A. Check OS

sw_vers uname -m

B. Install Docker Desktop

brew install --cask docker open -a Docker

C. Optional (Apple Silicon): Rosetta

softwareupdate --install-rosetta --agree-to-license

D. Verify Docker

docker --version docker compose version docker run --rm hello-world

Step 05

Initialize .env and Start Containers

cp .env.example .env docker compose up -d

Expected core services: `api`, `worker`, `worker_beat`, `web`, `plugin_daemon`, with dependencies like `db_postgres`, `redis`, `weaviate`, `nginx`, `ssrf_proxy`, and `sandbox`.

Step 10

Troubleshooting

Port 80 conflict

Stop the existing process on port 80 or remap the published port.

Container restarts / OOM

Increase Docker memory and inspect first failing service logs.

Windows filesystem performance

Run the project inside WSL Linux filesystem, not a mounted `C:` path.

Cross-subdomain auth issues

Set `COOKIE_DOMAIN` and `NEXT_PUBLIC_COOKIE_DOMAIN=1` in `.env` as needed.
